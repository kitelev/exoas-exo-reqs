# req(exo): a `concept__Concept`'s definition is a homoiconic COMPUTED VIEW from genus + differentia

> **Source:** Delta-2 of concept-typization ([[4107a70c-6fe7-4ff2-a807-339564606ef9|design-capture, 6 locks + panel revision]]) · Delta-1 TBox applied ([[b860de33-2673-4803-a0b0-3cc5911f30c0|RFC Delta-1]], 5 properties: genus/differentia/partOfSpeech/morpheme/description). The year-vision insight (Andrey): definition is redundant with genus+differentia (`Quarterly OKR` = genus(OKR) + differentia(quarterly)) — so you do not *write* a definition, you *declare* genus+differentia and it renders (Aristotelian transparency). The panel + empirical falsification softened F1 (blanket-retire) to **materialized-OR-computed** (~70% of stored definitions carry non-reconstructible narrative — enumerations, contrasts, historical notes, aphorisms — and are preserved).
>
> **⛤ Falsified surface-parity premise (recon, verify-before-assert, 2026-07-26):** the Delta-2 task AC said the definition "renders where free-text definition is currently shown (surface-parity)". Recon of `origin/main` found **`concept__Concept_definition` has NO custom render site in the plugin** — the only reference is `ConceptCreationService` (WRITE-only, at creation); it is displayed *only* by Obsidian's native Properties panel. So "surface-parity" targets the native Properties-panel definition VALUE row (the sole place a concept's definition shows), which this req patches. (Mirrors the F1/F3 falsification-note discipline of the design-capture — the AC premise was checked, not assumed.)
>
> **Materialized-OR-computed / dormant-until-Delta-3:** genus/differentia are greenfield (0 code refs, 0 typed instances now). The resolver is infrastructure; the computed branch is exercised by **production-shape synthetics** (real `scanVault` + synthetic typed concepts) and activates on real data after Delta-3.

## Job Story

When I look at a concept whose intensional structure I have declared (genus + differentia), I want its **definition to render as the composed `'<differentia> <genus>'` phrase** — a single source of truth in the graph, computed per-render — so I never hand-write a definition that can drift from its genus+differentia, and a concept that still needs narrative prose (no clean genus) keeps its stored free-text unchanged.
