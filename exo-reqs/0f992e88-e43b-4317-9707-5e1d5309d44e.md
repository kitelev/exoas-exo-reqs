# req(exo): a printed property falls back to the referenced asset's composed displayName

## Job Story

When a `exo__DisplayNameSpec` prints an object-property — «ОС a.a.aleksin **{{quarter}}**» —
and the referenced asset carries **no** `exo__Asset_label` (the shape
`exocmd__Grounding_omitLabel` / issue #4294 deliberately create), I want the printed value to be
the name that asset actually **renders as** («Q4-2025»), not the bare linkpath it falls back to
today («4222384a-e517-428f-ae57-ced7927c28a4»). A UID inside a composed name is not a name: it is
the absence of one, leaked into a sibling's title.

The workaround in use today is to hand-author a human `exo__Asset_label` on every such instance,
which duplicates the spec that already computes the same string and contradicts #4294.

## Statement (Gherkin)

```gherkin
# --- the new fallback ---

Scenario: a label-less target with its own spec prints its composed name
  Given a period__Quarter instance with NO exo__Asset_label and period__Quarter_number: 4
    And a exo__DisplayNameSpec for period__Quarter composing "Q" + number + "-2025"
    And a tbank__Review instance whose spec prints a exo__PrintedProperty on that quarter
  When the review's displayName is resolved
  Then it reads "ОС Q4-2025"
  And it does NOT contain the quarter's UID

# --- the three controls: what must NOT change ---

Scenario: a target WITH a label keeps printing the label
  Given the referenced asset carries exo__Asset_label "Q4-25"
    And it ALSO has a spec composing "Q4-2025"
  When the referring asset's displayName is resolved
  Then the printed value is "Q4-25" — the label, byte-identical to before this change
# The label stays FIRST. Measured: 0 of 50 884 live assets across the three canonical
# vaults change their rendered name under this requirement.

Scenario: a label-less target with NO composing spec keeps printing the linkpath
  Given the referenced asset has neither exo__Asset_label nor a participating spec
  When the referring asset's displayName is resolved
  Then the printed value is the bare linkpath, exactly as before
# Only a name the engine COMPOSED (provenance spec or tboxProjection) qualifies as the
# fallback. A settings classTemplate / default template rendered over a missing label
# yields debris such as "(period__Quarter)" — strictly worse than the UID it replaces.

Scenario: an explicit alias still wins
  Given the printed value is authored as [[<uid>|Q-четвёртый]]
  When the referring asset's displayName is resolved
  Then the printed value is "Q-четвёртый"
# The authored alias is the author's own override and is consulted before anything else,
# unchanged.

# --- boundedness (φ/EO: a recursive model pairs with a bounded interpreter) ---

Scenario: a reference cycle terminates
  Given two label-less assets A and B, each with a spec printing a reference to the other
  When A's displayName is resolved
  Then resolution terminates
  And the value printed for the re-entered target is its bare linkpath

Scenario: the re-render depth is capped
  Given a chain of label-less assets each printing a reference to the next
  When the head's displayName is resolved
  Then the walk stops at the declared depth cap and prints the linkpath beyond it
```

## Verification

- core unit — `DisplayNameTemplateEngine`: the option is consulted only after the label
  lookup fails; alias precedence; absent option = byte-identical output.
- core unit — `DisplayNameResolver`: provenance gate (spec / tboxProjection qualify,
  default / classTemplate do not), depth cap, cycle guard, resolver-absent fail-open.
- core integration — a UID-canon fixture vault carrying the two specs above, resolved
  through the real `PrintNameRuleService` + `FsVaultMetadataAdapter` path the CLI oracle
  uses, asserting the composed «ОС Q4-2025» and each of the three controls.
- revert-verify — one mutant per guard of the diff (enumerated from `git diff -U0`,
  integration-test-revert-verify §A8), each reddening its own axis and leaving the
  controls green.
- live-corpus delta — the whole-vault sweep re-run on the merged code: 0 changed names
  across vault-my / vault-tbank / vault-exodev, and the fixture flip shown in both
  directions.
