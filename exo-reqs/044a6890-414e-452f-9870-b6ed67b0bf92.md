## Контекст

Кнопки команд гейтятся **precondition-ASK**, а не наличием ассета в store. Часть ASK —
**data-driven**: они ходят по данным на два хопа. Пример из прода, `38ff3c61`
(«Source ontology declares an archive ontology»):

```sparql
ASK { $target exo:Asset_isDefinedBy ?onto .
      ?onto   exo:Ontology_archiveOntology ?a . }
```

Второй хоп читает свойство **онтологии**, а не таргета.

`LazyAssetGraphLoader` — render-authoritative для кнопок
(`DynamicCommandButtonGroupBuilder:418`) — обходил три предиката:
`exo__Instance_class`, `exo__Class_superClass`, `exo__Asset_prototype`.
`exo__Asset_isDefinedBy` в списке **не было** ⇒ онтология в store на рендере не попадала
⇒ ASK ложен ⇒ кнопка скрыта, пока не отработает полный `convertVault()`.

TBox-бутстрап это не покрывает: `lazyBootstrapFolders` перечисляет
`exo/ ems/ ems-commands/ ims/ exocmd/`, а личная онтология (напр. `$my-efforts`) лежит в
`assetspaces/<owner>/exoas-my/my-efforts/` — **ноль совпадений** (замер на живом vault).

**Замер на десктопе 2026-08-29** (v16.235.2, холодный кэш после reload): **3 из 7** кнопок;
через 25 с — 7 из 7. Заявка Tier 1 (`req 7d00a60b`, чтение frontmatter с диска) на это
не влияет: она чинит слой ниже, а гейт здесь — предусловие, а не наличие ассета.

## Сценарии

```gherkin
Feature: онтология таргета входит в store на рендере (data-driven precondition)

  Scenario: ASK через exo:Asset_isDefinedBy вычисляется при холодном кэше
    Given ассет A несёт "exo__Asset_isDefinedBy: [[O]]"
      And онтология O несёт "exo__Ontology_archiveOntology: [[X]]"
      And metadataCache ещё не прогрет, convertVault() не завершён
     When рендер запрашивает ensureFileLoaded(A)
     Then файл O загружен ровно один раз
      And в store присутствует триплъ (O, exo:Ontology_archiveOntology, X)

  Scenario: радиус НЕ расширяется до «идти по любой IRI»
    Given ассет A несёт "exo__Asset_relates: [[N]]"
     When рендер запрашивает ensureFileLoaded(A)
     Then файл N НЕ загружен
      And loadedCount равен 1
```

## Цена (замерена до реализации)

8857 ассетов `vault-my` ссылаются на **145** различных онтологий ⇒ `loadedIRIs`-кэш
схлопывает добавленный хоп до «не более одного лишнего файла на онтологию за сессию»,
а не на ассет.

## Границы

Общий AST-обход precondition с ретраем остаётся отложенным (RFC `c7da0bca` Q4). Это
требование покрывает **хоп до онтологии**, а не произвольные предикаты.
